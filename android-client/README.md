# 电脑监控 · 安卓客户端

这是电脑运行监控项目面向老旧 Android 手机和平板开发的原生客户端。它希望让已经退出日常使用、但仍能正常联网和显示画面的设备继续发挥余热，成为电脑状态屏、桌面时钟、应用启动面板和电子相册。

客户端通过可信局域网连接 Windows 监控服务，不依赖云服务、在线账号或 Google Play 服务。监控主界面使用原生 Kotlin 和 Android View 实现，针对横屏平板、低性能设备和长期亮屏场景设计。

## 兼容性

- 支持 **Android 5.0（API 21）及以上版本**，重点兼容 Android 5–7 老设备
- 使用系统 API，保持较小的安装体积和较低的运行负担
- 使用局域网 HTTP 兼容旧系统，不应连接到公网监控服务

## 功能

- 显示电脑 CPU、内存、磁盘、网络、温度、进程和监听端口
- 显示平板自身的 CPU、电量、充电状态和开机时长
- 万年历大时钟、CPU 阈值告警和进程表排序
- 可注册为 HOME 桌面，并从应用启动器打开设备中的其他应用
- 空闲后自动进入图片幻灯片，触摸屏幕即可返回监控界面
- 支持图片缓存、重启续播、缩略图列表和单张全屏预览
- 缓存空间低于 200 MiB 时自动关闭缓存，避免占满旧设备存储

## 使用步骤

1. **电脑端**：在项目根目录启动监控程序
   ```powershell
   .\bin\monitor.exe
   ```
   启动后终端会显示「手机/局域网设备访问：http://192.168.x.x:8765/」

2. **手机端**：安装 `app-debug.apk`（首次安装需允许"未知来源"应用）

3. **连接**：打开应用，输入终端显示的地址（手机与电脑需在同一 Wi-Fi）

4. 右上角齿轮按钮可随时更换地址；连接失败时会提示重试

## 重新构建（可选）

本机已配置好 Android Studio SDK 与 Gradle，修改代码后可直接重新编译：

```powershell
cd android-client
.\gradlew.bat assembleDebug
```

产物位置：`app\build\outputs\apk\debug\app-debug.apk`
